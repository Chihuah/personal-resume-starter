# 個人簡歷網頁設計（Starter）

## 目標
建立一個專業的個人簡歷網頁，展示技能、經歷、作品集；練習使用 Copilot 建立結構與樣式。

## 必要功能
- 個人資訊區塊（姓名、照片、聯絡方式）
- 技能展示區（進度條或標籤雲）
- 工作經歷時間軸
- 專案作品集展示（卡片式佈局）
- 響應式設計（含 `<meta name="viewport">`)
- 平滑捲動與動畫效果

## 進階挑戰（加分）
- 深色模式切換
- 捲動動畫（AOS 或 Intersection Observer）
- 列印樣式（印成 PDF）
- 聯絡表單（EmailJS 等）
